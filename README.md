## What it does

- Automatically detects YouTube comment languages.
- Leaves **English** and **Turkish** comments untouched.
- Translates other detected languages into **English**.
- Handles newly loaded comments and replies while you scroll.
- Uses a simple **one-click toolbar toggle**.
- Has **no popup** and no settings screen to open.
- Requires **no API key** from the user.

This means comments in languages such as Russian, Georgian, Polish, Portuguese, Spanish, Norwegian and many others can be shown with an English translation automatically.

## ON / OFF

The logo itself never changes.

The browser toolbar badge is controlled by code:

- **ON** — green badge
- **OFF** — gray badge

Click the extension icon once to switch state.

## Example

Original comment:

> Очень хорошее видео, спасибо!

The extension adds:

> **Translated from RU**  
> Very good video, thank you!


## Privacy

- No account login is required.
- No API keys are requested from the user.
- The extension does not save your YouTube comments.
- Comment text that needs translation is sent to the translation service so the English translation can be returned.

## Notes

YouTube can change its page structure over time. If that happens, the comment selectors may eventually need a small update.
